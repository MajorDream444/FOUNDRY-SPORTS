## Run the discovery prototype

Open [`prototype/index.html`](prototype/index.html) in a modern browser. No dependency installation or API key is required. Alternatively, from this directory run:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080/prototype/`. All records are fictional and saved only in your browser. See the [walkthrough and limitations](prototype/README.md).
